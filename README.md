# AI Real-Time Assistant

An AI helper that can answer questions, use real-time web search, verify information using latest data, call tools, and remember previous conversation context locally.

## Features

- AI agent architecture
- Real-time internet search
- Tool calling
- Local conversation memory
- Source-based answers
- GitHub-ready structure
- Runs in VS Code terminal

## Tech Stack

- Python
- OpenAI API
- Tool Calling
- DDGS / DuckDuckGo Search
- Local JSON memory
- python-dotenv
